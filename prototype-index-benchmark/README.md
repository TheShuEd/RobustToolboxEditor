# Прототип — выброшенный код (issue #5)

Первоисточник для замеров и находок, зафиксированных в резолюции
[issue #5 «Индекс прототипов и бюджет производительности»](https://github.com/crystallpunk-14/SS14Editor/issues/5).
Не переносится в продакшн как есть.

## Что здесь есть

- `index.mjs` — бенчмарк: обход `Resources/Prototypes/**` реального форка, парсинг через
  `yaml` (eemeli), резолв наследования, замер холодного старта / инкремента / кэша.
- `profile.mjs` — разбивка времени парсинга по стадиям.
- `bom-scan.mjs` — сканирует форк на файлы с ведущим UTF-8 BOM.
- `extract-fixtures.mjs` — достаёт реальные показательные прототипы из форка в `fixtures.json`.
- `inheritance-demo.html` — интерактивное демо резолва наследования на реальных фикстурах.
- `fixtures.json` — сохранённый вывод `extract-fixtures.mjs`.

Запуск: `npm install`, затем `node index.mjs <путь-к-форку>` (нужен реальный чекаут форка
SS14 с `Resources/Prototypes/`, например `crystall-edge`).

## ⚠️ `inheritance-demo.html` реализует ОТВЕРГНУТЫЙ алгоритм

Демо хардкодит спецкейсы на полях `abstract` и `components` (`combineMapping`/`combineComponents`
в `<script>`). Это нарушает принцип однородности, зафиксированный на карте
(«реестр обработчиков по C#-типу, `ComponentRegistry` — рядовой обработчик, а не особый случай»),
и был явно отвергнут в процессе резолва #5.

Принятый дизайн — дженерик-диспатч по метаданным контракта #4
(`[AlwaysPushInheritance]` / `[NeverPushInheritance]` / `ITypeInheritanceHandler`), **не**
реализован в этом демо. Демо оставлено только как:

1. проверка реального поведения движка (`SerializationManager.Composition.cs`,
   `PrototypeManager.cs`) на живых фикстурах форка — то есть источник фактов о том,
   *что* должен делать резолвер;
2. иллюстрация того, как не надо — конкретный пример спецкейс-ловушки.

Не использовать как образец реализации.

## Эмпирические находки (сохранены как данность, вошли в резолюцию #5)

- **Холодный старт**: однопоточный парсинг всего форка `crystall-edge`
  (2760 файлов прототипов + 7 движковых, 9.6 МБ, ~25 200 документов) через `yaml` — ~7 с,
  +22 МБ heap. Резолв наследования всех kind'ов — 68 мс.
- **BOM-баг**: 9.1% файлов форка (250 из 2760) начинаются с UTF-8 BOM. `yaml` (eemeli) не
  снимает BOM сам и молча заваливает разбор всего документа (0 записей, без ошибки на уровне
  файла). Фикс: `if (text.charCodeAt(0) === 0xFEFF) text = text.slice(1)` перед парсингом.
