# SS14Editor

Плагин VS Code для редактирования YAML-прототипов в форках SS14 на движке RobustToolbox.

## Language

**ResPath**:
Движковый C#-тип пути к файлу под `Resources/`. Поле, напрямую типизированное `ResPath`, — не то же самое, что поле типа `SpriteSpecifier`/`SoundSpecifier`, даже если оно тоже в итоге хранит путь: диспетчеризация по объявленному типу видит только первое.
_Avoid_: "путь к ресурсу" как общий термин без уточнения, обёрнут он в специфаер или нет.

**SpriteSpecifier / SoundSpecifier**:
Полиморфные (union) C#-типы-обёртки над `ResPath`: `SpriteSpecifier` — RSI+состояние либо голая текстура; `SoundSpecifier` — путь к файлу (`SoundPathSpecifier`) либо ссылка на `soundCollection`-прототип (`SoundCollectionSpecifier`). Классифицируются как единый непрозрачный вид — вложенные `ResPath`/`string`-поля внутри них не видны дженерик-диспетчеризации по типу.
_Avoid_: путать с `ResPath` — поле типа `SpriteSpecifier` не значит "поле типа ResPath".

**Реестр поведений при наследовании** (#5):
Диспатч внутри индекса прототипов по метаданным поля (`[AlwaysPushInheritance]`/`[NeverPushInheritance]`/зарегистрированный `ITypeInheritanceHandler`) — решает, **как резолвится значение** поля при наследовании: перекрытие потомком, рекурсивный merge, отсутствие наследования вовсе. Отвечает индекс, не UI.
_Avoid_: называть просто «реестр» без уточнения — путается с реестром обработчиков типов ниже. Разные ключи диспетчеризации: этот — по атрибутам наследования поля, тот — по C#-типу поля.

**Реестр обработчиков типов** (UI, #9, [ADR-0003](docs/adr/0003-type-handler-dispatch-by-fieldkind.md)):
Диспатч внутри инспектора по `FieldKind` поля — решает, **каким обработчиком поле рендерится и редактируется** (примитив, `list`/`map`/`tuple`/`object`, `ComponentRegistry`, будущие `SpriteSpecifier`/`SoundSpecifier`). Рекурсия handler-driven: составные обработчики — рядовые записи того же реестра, что и примитивы, сами вызывающие реестр для вложенных типов; ни один обработчик не привилегирован.
_Avoid_: называть просто «реестр» без уточнения — путается с реестром поведений при наследовании выше. Путать ключ реестра с `FullType` — см. `FieldKind`.

**FieldKind**:
Предвычисленная на C#-стороне (экстрактор метаданных, #4) грубая структурная категория типа поля (`boolean`/`list`/`map`/`enum`/`protoId`/`componentRegistry`/…) — уже развернувшая `Nullable<T>`, generic-коллекции через интерфейсы, аргумент `ProtoId<T>` и `[Flags]`-enum. Ключ диспетчеризации реестра обработчиков типов.
_Avoid_: путать с `FullType` (точное C#-имя типа, включая закрытые generic-аргументы) — `FullType` едет в контракте как полезная нагрузка для конкретных обработчиков, не как ключ поиска.

**Read-only (унаследованное значение)**:
Значение поля показывается, но не редактируется напрямую, потому что пришло от родителя по цепочке наследования. Материализуется в текст дочернего прототипа только явным жестом «переопределить» (#10) — до этого жеста правка запрещена, но обратима в любой момент.
_Avoid_: путать с read-only движковых прототипов ниже — там запрет постоянный, здесь временный до явного жеста. Не путать также с полем-алиасом ниже — разные механизмы (наследование по `parent:` не то же самое, что YAML-алиас), хоть оба показывают «чужое» значение как read-only.

**Якорное поле / поле-алиас** (#13):
Поле, резолвящееся в YAML `&anchor` (якорное — объявляющее значение) или `*anchor` (алиас — ссылающееся на него). Оба помечены в инспекторе одинаково — акцентным цветом и иконкой якоря с его именем. Якорное поле редактируется как обычное поле своего `FieldKind`: правка на месте (#10) долетает до всех алиасов через re-parse без дополнительного кода, потому что алиас — ссылка на узел, а не копия текста. Поле-алиас — read-only безусловно, без перехода к якорному полю; инспектор показывает резолвленное (унаследованное от якоря) значение. Материализация алиаса в независимый скаляр («открепить от якоря») — за скоуп v1.
_Avoid_: путать с read-only унаследованного значения выше — разные механизмы, у которых read-only совпадает лишь по проявлению.

**Read-only (движковый прототип)**:
Значение поля в прототипе из `RobustToolbox/Resources/EnginePrototypes/` (сабмодуль, `engine: true` в индексе #5) — видно в автокомплите/go-to-def/наследовании, но правки-интенты в файлы сабмодуля запрещены безусловно. Жеста «переопределить» здесь нет вовсе: запрет не снимается, это не тот же механизм, что унаследованное значение.
_Avoid_: путать с read-only унаследованного значения выше — там запрет временный и снимаемый, здесь постоянный.
